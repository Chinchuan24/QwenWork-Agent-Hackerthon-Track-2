## Evidence Rules

A claim is an assertion about implemented behavior, measured results, provenance, availability, security or legal status. Headings, opinions, targets, conditional scripts, instructions and illustrative examples are not each treated as factual claims. Related assertions are grouped by scope below rather than pretending every sentence is a separate measurement.

Static source and test assertions establish implementation/test scope, not fresh execution. Dated progress/handoff receipts are reported historical evidence, not authenticated run logs or current acceptance. Stored JSON is inspectable saved backend evidence, not independently reverified signatures, live AI, browser navigation or sponsor acceptance. No original external-source fetches were repeated. 'No proof' means no sufficient proof in this inspection, not proof of absence.
